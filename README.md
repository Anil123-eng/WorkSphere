# WorkSphere – Assessment 01

## Overview
WorkSphere is a multi-tenant project management platform.

## Technology
- Next.js App Router
- TypeScript
- Tailwind CSS

## Implemented
- Responsive homepage
- Platform Administrator page
- Organization Owner page
- Project Manager page
- Team Member page
- Shared workspace layout
- Reusable workspace form

## Run locally
1. Run `npm install`
2. Run `npm run dev`
3. Open http://localhost:3000

## Validation
- `npm run lint`
- `npm run build`

## Current limitation
Authentication, authorization, and backend integration are not yet implemented. These are addressed in their relevant assessments.
